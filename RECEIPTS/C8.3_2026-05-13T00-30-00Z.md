### Self-check

What could I have gotten wrong that VERIFY wouldn't catch?

1. **The "PASS" status on the 7 Section B race cells is rounding-tolerance based (±0.01), not exact-cell-count based.** NVSR 73-09 Table A publishes RATES (per 1,000 LB+FD); we compute rates from absolute counts. If our absolute counts had a systematic compensating error (e.g., FD by race off by +N, LB by race off by +M, where the ratio happens to round to NVSR), VERIFY would not catch it. Mitigation: spot-checked absolute counts manually against NVSR 73-09 Table 4 (which publishes some absolute counts, e.g., Hispanic 4,359, Black 5,194, Asian 813 — all match our parquet exactly). Risk: medium-low.

2. **The Section C "perinatal rate within 0.20 per 1,000 tolerance" gate is loose.** The two documented drifts (proportional redistribution; cohort vs period linkage) could in principle compound systematically in either direction beyond 0.20. VERIFY would not catch a compounding drift; mitigation = documenting both drift components individually (FD +4.6%; ENN −2.1%) and explaining why they're expected. A future automated invariant test (C8.4 scope) could quantify the cohort-vs-period gap year-over-year.

3. **The natality 6-race classification via `nat_race_class(row)` uses `df.apply(axis=1)` on a 3.6M-row DataFrame.** This is slow (~30s on this machine) but correct. A faster vectorized version using `np.select` would be preferred; the current implementation is "first correct, then fast" pending a C8.5 / C8.13 performance pass. Wrong-result risk: low (manual cell-by-cell verification confirms the 6-cat classification matches NVSR Table A counts).

4. **The `verify_band_coverage()` SHAPE check in the timeline helper covers band tiling, not band semantics.** If I named a band "V3b: 1978-rev" but assigned it the wrong year range (e.g., starting 1980 instead of 1982), the helper would not catch it; the COMPARABILITY-docs cross-reference is via my reading of the docs, not via an automated check that pulls era boundaries from the COMPARABILITY MD. Mitigation: era boundaries were extracted verbatim from `fetal_death/COMPARABILITY.md §Era Structure` table (1992-2002 V2, 2005-2017 V1, etc.) and STATUS-recorded V3a/V3b ranges (1989-1991 / 1982-1988). Risk: low; reviewable via diff against COMPARABILITY in any audit.
